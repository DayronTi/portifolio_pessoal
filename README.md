# 🤖 Bruninho - Chatbot do Portfólio

Bruninho é um chatbot desenvolvido em **Python e Django** para atuar como assistente virtual do meu portfólio profissional.

Seu objetivo é apresentar minha trajetória, experiências, projetos e competências técnicas de forma interativa, permitindo que recrutadores e visitantes conheçam melhor meu perfil como **Desenvolvedor RPA e Python Developer**.

## 🚀 Funcionalidades

* Chat em tempo real integrado ao portfólio;
* Respostas sobre minha trajetória profissional;
* Apresentação de projetos e tecnologias;
* Integração com a API da Groq utilizando modelos de IA;
* Interface flutuante e responsiva;
* Arquitetura preparada para futuras evoluções, como memória de conversas e RAG.

## 🛠️ Tecnologias Utilizadas

* Python
* Django
* Django REST Framework
* JavaScript
* HTML5 e CSS3
* Groq API
* Git e GitHub

## 📌 Objetivos do Projeto

Este projeto foi desenvolvido com o objetivo de:

* Aprimorar conhecimentos em desenvolvimento web com Django;
* Estudar integração de Inteligência Artificial em aplicações reais;
* Construir um chatbot personalizado;
* Demonstrar habilidades em Python, APIs e desenvolvimento de soluções inteligentes.

## 📷 Demonstração

O Bruninho está integrado ao meu portfólio e pode responder perguntas como:

* Quem é o Bruno?
* Quais tecnologias ele domina?
* Quais projetos ele desenvolveu?
* Qual sua experiência com automações e RPA?
